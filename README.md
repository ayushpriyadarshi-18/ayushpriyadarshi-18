## Featured Work

### Current Research: β⁺-Emitter Coincidence-Summing Corrections

Working with Prof. Anil Kumar Gourishetty on geometry-dependent coincidence-summing corrections for Na-22, O-14, and Sc-44 in a 32-element near-4π NaI(Tl) soccer-ball detector array.

I extended my thesis software to implement custom radioactive sources from nuclear decay schemes, reconstruct the published Byun eight-block reference detector, calculate angular factors, and execute 10^8-event campaigns. The implementation reproduces published reference factors within 2.3% and the detector model has been benchmarked against published experimental measurements for the physical TIFR array.

A peer-reviewed journal manuscript is planned, with confirmed second authorship. Unpublished code, detector-specific results, tables, and plots remain private pending manuscript development and supervisor approval.

### Geant4 Detector Simulation Pipeline

A Python-assisted Geant4 workflow for automated scintillation detector response simulations.

**Repository:**  
https://github.com/ayushpriyadarshi-18/geant4-detector-simulation-pipeline

**Website:**  
https://ayushpriyadarshi-18.github.io

The pipeline integrates a configurable Geant4 C++ detector simulation backend with Python tools for macro generation, campaign execution, ROOT-file validation, deposited-energy spectrum generation, peak-count extraction, total-count extraction, plotting, and output organisation.

It supports solid cylindrical, hollow annular, and near-4π soccer-ball detector geometries, along with scintillator materials such as NaI, LaBr3, CsI, BGO, GGAG, and PbWO4.

This work forms the basis of my undergraduate thesis, a first-author paper accepted for poster presentation at IEEE Nuclear Science Symposium 2026, and my current detector-physics research.
